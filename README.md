**enda-частично шуточная библиотека а частично полезная.**
Полезные стороны:
*1. есть точная замена pause из batch.*
*2. простой repl на eval(защиты нет но есть дисклеймер прочитав который пользователь берёт ответственность на себя).*
*3. форматированый вывод json, для новичков это хорошо потому что не надо много писать и импортировать json самому.*
*4. открывалка веб страниц, не нужно импортировать webbrowser.*
*5. есть очистка консоли*

Шуточные стороны:
*1. Открытие rickroll*
*2. колокольня, если вызвать эту функцию то пойдёт звон который невозможно остановить(без закрытия программы).*
*3. открытие http.cat, вроде бы и шуточное а вроде бы и полезное(например изучать http коды узнавая через код).*


**Список команд:**
enda.clr() - очистить экран.
enda.kolokol() - колокольня которую не остановить.
enda.httpcat() - открывает http.cat, по дефолту путь /500 но поддерживает аргументы типа enda.httpcat(404).
enda.wow() - открывает рикролл.
enda.git() - открывает github страницу библиотеки.
enda.url("example.com") - открывает нужную страницу.
enda.pause() - аналог pause в batch.
enda.exe() - repl на eval.
enda.json(base) - выполняет print(json.dumps(base, ensure_ascii=False, indent=2)) то есть выводит красиво отфарматированый json.
enda.info() - выводит информацию о библиотеке.

**Некоторые команды поддерживают локали**
локали 3 штуки, en-английский, ru-русский, by-беларусский/трасянка латиницей. для локалей исползуются классы. пример использования: enda.en.pause().
